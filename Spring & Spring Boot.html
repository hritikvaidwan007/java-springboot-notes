Core Concept

What is a Spring Bean?

A Spring Bean is any object instantiated, assembled, and managed by the Spring IoC container. Beans form the backbone of every Spring application.

Key Characteristics

  • Created & wired by the container (not new)
  • Lifecycle fully managed by the container
  • Configured via annotations, XML, or Java config
  • Stored in BeanFactory / ApplicationContext
  • Dependencies injected automatically (DI)
  • Default scope is singleton
  • Thread-safe only if stateless (no mutable fields)

Stereotype Annotations

@Component       // Generic managed bean
@Service         // Business logic layer
@Repository      // Data access (exception transl.)
@Controller      // Web / MVC layer
@RestController  // = @Controller + @ResponseBody
@Configuration   // Java-based config class
@Bean            // Factory method in @Configuration

Naming

Default bean name = class name with lowercase first letter. Override with @Service("myName").

Aspect-Oriented Programming

How AOP Proxies Wrap Bean Method Calls

Example Aspect

@Aspect @Component
public class LoggingAspect {
  @Before("execution(* com.app.service.*.*(..))")
  public void logBefore(JoinPoint jp) {
    log.info("Call: " + jp.getSignature());
  }

  @Around("execution(* com.app.repo.*.*(..))")
  public Object time(ProceedingJoinPoint p)
      throws Throwable {
    long s = System.currentTimeMillis();
    Object r = p.proceed();
    log.info("ms: "
      + (System.currentTimeMillis() - s));
    return r;
  }

  // Custom annotation pointcut
  @Around("@annotation(auditable)")
  public Object audit(ProceedingJoinPoint p,
      Auditable auditable) throws Throwable {
    auditLog.log(p.getSignature(), auditable.action());
    return p.proceed();
  }
}

Advice Types

@BeforeBefore method execution
@AfterAfter (finally, always runs)
@AfterReturningAfter successful return
@AfterThrowingAfter exception thrown
@AroundFull wrap (most powerful)

Security Filter Chain

Security Filter Chain Config

@Configuration
@EnableWebSecurity
public class SecurityConfig {

  @Bean
  SecurityFilterChain filterChain(
      HttpSecurity http) throws Exception {
    return http
      .csrf(c -> c.disable())
      .sessionManagement(s -> s
        .sessionCreationPolicy(
          SessionCreationPolicy.STATELESS))
      .authorizeHttpRequests(auth -> auth
        .requestMatchers("/api/public/**")
          .permitAll()
        .requestMatchers("/api/admin/**")
          .hasRole("ADMIN")
        .anyRequest().authenticated())
      .addFilterBefore(jwtFilter,
        UsernamePasswordAuthenticationFilter.class)
      .exceptionHandling(e -> e
        .authenticationEntryPoint(entryPoint)
        .accessDeniedHandler(deniedHandler))
      .cors(c -> c.configurationSource(corsSrc))
      .build();
  }

  @Bean
  PasswordEncoder encoder() {
    return new BCryptPasswordEncoder();
  }
}

@Entity
@Table(name = "users")
@EntityListeners(AuditingEntityListener.class)
public class User {
  @Id

    GenerationType.IDENTITY)
  private Long id;

  @Column(nullable = false, length = 100)
  private String name;

  @Column(unique = true)
  private String email;

  @Enumerated(EnumType.STRING)
  private Role role;

  @ManyToOne(fetch = FetchType.LAZY)
  @JoinColumn(name = "dept_id")
  private Department department;

  @OneToMany(mappedBy = "user",
    cascade = CascadeType.ALL,
    orphanRemoval = true)
  private List<Order> orders = new ArrayList<>();

  @CreatedDate
  private LocalDateTime createdAt;

  @LastModifiedDate
  private LocalDateTime updatedAt;

  @Version
  private Long version; // optimistic locking
}

Repository Interface

public interface UserRepository
    extends JpaRepository<User, Long> {

  // Derived query
  Optional<User> findByEmail(String email);
  List<User> findByNameContainingIgnoreCase(
      String name);
  boolean existsByEmail(String email);
  long countByRole(Role role);

  // JPQL query
  @Query("SELECT u FROM User u WHERE u.department.id = :deptId")
  Page<User> findByDept(
      @Param("deptId") Long deptId,
      Pageable pageable);

  // Native SQL
  @Query(value = "SELECT * FROM users WHERE active = true",
    nativeQuery = true)
  List<User> findActiveUsers();

  // JOIN FETCH (avoid N+1)
  @Query("SELECT u FROM User u JOIN FETCH u.department")
  List<User> findAllWithDept();

  // EntityGraph
  @EntityGraph(attributePaths = {"department", "orders"})
  List<User> findAll();

  // Modifying query
  @Modifying
  @Query("UPDATE User u SET u.active = false WHERE u.lastLogin < :date")
  int deactivateInactive(
      @Param("date") LocalDateTime date);

  // Projections (interface-based)
  List<UserSummary> findByRole(Role role);
}

Error Handling EXPANDED

Global Exception Handling

@RestControllerAdvice
public class GlobalExceptionHandler {

  // Resource not found
  @ExceptionHandler(
    ResourceNotFoundException.class)
  public ResponseEntity<ApiError> notFound(
      ResourceNotFoundException ex,
      WebRequest req) {
    return build(404, ex.getMessage(), req);
  }

  // Validation errors
  @ExceptionHandler(
    MethodArgumentNotValidException.class)
  public ResponseEntity<ApiError> validation(
      MethodArgumentNotValidException ex) {
    Map<String,String> errs = new HashMap<>();
    ex.getBindingResult()
      .getFieldErrors().forEach(e ->
        errs.put(e.getField(),
               e.getDefaultMessage()));
    return ResponseEntity.badRequest()
      .body(new ApiError(400, "Validation", errs));
  }

  // Access denied
  @ExceptionHandler(
    AccessDeniedException.class)
  public ResponseEntity<ApiError> denied(
      AccessDeniedException ex) {
    return build(403, "Access denied", null);
  }

  // Catch-all
  @ExceptionHandler(Exception.class)
  public ResponseEntity<ApiError> fallback(
      Exception ex, WebRequest req) {
    log.error("Unhandled", ex);
    return build(500, "Internal error", req);
  }
}

Cache Annotations

@Service
public class ProductService {

  // Cache result
  @Cacheable(value = "products",
    key = "#id")
  public Product getById(Long id) { ... }

  // Cache with condition
  @Cacheable(value = "products",
    key = "#name",
    unless = "#result == null",
    condition = "#name.length() > 3")
  public Product findByName(String n) { ... }

  // Update cache
  @CachePut(value = "products",
    key = "#product.id")
  public Product update(Product p) { ... }

  @CacheEvict(value = "products",
    key = "#id")
  public void delete(Long id) { ... }

  // Evict all entries
  @CacheEvict(value = "products",
    allEntries = true)
  public void clearCache() { }

  // Multiple caches
  @Caching(evict = {
    @CacheEvict("products"),
    @CacheEvict("inventory")
  })
  public void resetAll() { }
}

Async Gotcha

  • Must be called from outside the class (proxy)
  • Return void, Future, or CompletableFuture
  • Exceptions lost unless you use AsyncUncaughtExceptionHandler

@Service
public class PaymentGateway {
  private final RestClient client;

  public PaymentGateway(
      RestClient.Builder builder) {
    this.client = builder
      .baseUrl("https://api.payment.com")
      .defaultHeader("Authorization",
        "Bearer ${api.key}")
      .build();

    return client.post()
      .uri("/v1/charges")
      .body(req)
      .retrieve()
      .body(PaymentResponse.class);
  }
}

      .build();

Pitfalls & Tips

Common Gotchas

Dependencies

  • Circular: @Lazy or redesign
  • Prototype in Singleton: ObjectProvider<T>
  • Self-invocation: bypasses proxy
  • Scan miss: add @ComponentScan

Data & JPA

  • N+1: @EntityGraph / JOIN FETCH
  • @Configuration vs @Component: only @Configuration proxies @Bean
  • ddl-auto=update: never in prod
  • Lazy loading: set open-in-view=false

Production

  • Actuator: secure /actuator
  • Graceful shutdown: server.shutdown=graceful
  • Connection pool: tune HikariCP
  • HTTPS: terminate at reverse proxy
